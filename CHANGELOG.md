# Changelog

Notable changes to PICK are recorded here.

## 0.1.8 — Release fixes

- Fixed release packaging by removing copied terminal prompt text from the script boundaries.
- Added `extenstion` as a compatibility alias for `extension`.
- Retained the 0.1.7 Command Centre, Memory, Missions, Repair, and Extensions features.
- Preserved the existing backup/restore and shell integration.

## 0.1.7 — Feature build

- Added the Command Centre, Memory, Missions, Repair guidance, and local Extensions features.
- Added Doctor, personal actions, theme preview, and audio inspection commands.

Earlier development history may not be fully documented in this initial public changelog.
